# <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><polygon points="23 7 16 12 23 17 23 7"/><rect x="1" y="5" width="15" height="14" rx="2" ry="2"/></svg> Apresentação do Projeto

## <svg xmlns="http://www.w3.org/2000/svg" width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="12" cy="12" r="10"/><line x1="12" y1="16" x2="12" y2="12"/><line x1="12" y1="8" x2="12.01" y2="8"/></svg> Visão geral

O VCF OS & Agenda é um painel web para organizar contatos em formato VCF com fluxo simples:

1. Importar arquivo `.vcf`
2. Editar contatos individualmente ou em lote
3. Organizar lixeira de forma segura
4. Vincular eventos de agenda aos contatos
5. Exportar base atualizada

- Usuários que precisam higienizar VCF para WAHA/Evolution
- Times que desejam uma ferramenta local, sem backend obrigatório
