# Apresentação do Projeto

## Visão geral

O VCF OS & Agenda é um painel web para organizar contatos em formato VCF com fluxo simples:

1. Importar arquivo `.vcf`
2. Editar contatos individualmente ou em lote
3. Organizar lixeira de forma segura
4. Vincular eventos de agenda aos contatos
5. Exportar base atualizada

## Público-alvo

- Operações comerciais que trabalham com listas de contatos
- Usuários que precisam higienizar VCF para WAHA/Evolution
- Times que desejam uma ferramenta local, sem backend obrigatório

## Diferenciais

- Mobile-first real (celular como prioridade)
- Edição inline rápida
- Ações em lote para produtividade
- Agenda local persistida em `localStorage`
- Instalação PWA para uso como app
